🖼 アップロード済みメディア

    HTML 出力

    テスト手順

    1. テキストを入力・選択して popm を表示
    2. 下部モーダルの 🖼 メディア をクリック
    3. ファイル選択 で画像を選ぶ
    4. ⏳ プレースホルダー → 1.5 秒後に画像に差し替わることを確認
    5. 右パネルに mid-xxx が表示される
    6. 保存ボタンで [[mid-xxx]] に変換されることを確認
    💡 URL 欄に https://placehold.co/400x300 などを入力して URL 挿入もテストできます
